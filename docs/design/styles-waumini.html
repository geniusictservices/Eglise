Quatre styles pour la même application

Chaque style est appliqué au même écran : le tableau de bord de la paroisse de Himbi, tel qu’il sera quand les finances et les membres seront en place. Regardez la version téléphone et la version ordinateur, puis dites-moi lequel vous parle, ce que vous aimez et ce que vous changeriez. Les chiffres sont fictifs.

A. Clair et netB. Comme le mobile moneyC. Chaleureux, waxD. Sobre et professionnel

A Clair et net

Fond blanc, beaucoup d’espace, une seule couleur forte (le bleu-vert du logo) et l’ocre pour l’action principale. L’esprit d’une application bancaire moderne : lisible, calme, sérieuse.

Pour qui : tout le monde, du pasteur au trésorierForce : très lisible, vieillit bienRisque : peu d’identité africaine

À vous de choisir

Répondez-moi simplement dans la conversation, par exemple : « B, avec les couleurs de C ».

  1. Quel style vous parle le plus : A, B, C ou D ? On peut aussi en mélanger deux.
  2. Qu’est-ce qui ne vous plaisait pas dans la première version : les couleurs, la police, la barre latérale foncée, trop de texte, pas assez d’icônes… ?
  3. Avez-vous une application ou un site dont vous aimez le style ? Son nom suffit.
